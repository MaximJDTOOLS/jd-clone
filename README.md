# 🕺 Just Dance Clone

Игра в стиле Just Dance с трекингом позы через **MediaPipe Pose**, редактором танцев и системой скоринга.

## Возможности

- **Трекинг позы** через веб-камеру с MediaPipe (33 ключевые точки скелета)
- **Редактор танцев** — запись поз с камеры в реальном времени, привязка к таймингу
- **Свои танцы** — загружайте аудио/видео, записывайте движения, сохраняйте в `.dance` файл
- **Импорт/экспорт** — делитесь `.dance` файлами с друзьями
- **Скоринг** — сравнение поз игрока с эталоном в реальном времени (косинусное сходство)
- **Система комбо** и оценок (S/A/B/C/D)
- **Видео + камера** — параллельное воспроизведение целевого видео и камеры игрока

## Установка

```bash
pip install -r requirements.txt
```

### Требования

- Python 3.9–3.11
- Веб-камера
- MediaPipe (требует поддержки OpenGL)
- Достаточное освещение для трекинга

## Запуск

```bash
python main.py
```

## Как пользоваться

### Создать танец

1. Откройте **Редактор танцев**
2. Заполните название, сложность, BPM, автора
3. Загрузите аудио (mp3/wav/ogg) и/или видео (mp4/avi)
4. Нажмите **«Запустить камеру»**
5. Нажмите **«Начать запись»** и танцуйте перед камерой
6. Нажмите **«Остановить запись»**
7. Нажмите **«Сохранить танец»**

### Играть

1. Выберите танец в списке
2. Нажмите **«Играть»**
3. Встаньте перед камерой и повторяйте движения
4. В конце получите оценку (S/A/B/C/D)

### Импорт чужих танцев

Нажмите **«Импортировать .dance»** и выберите файл.

  "bpm": 120.0,
  "difficulty": "Normal",

  "frames": [
    {
      "timestamp": 0.0,
      "landmarks": [[x, y, z, visibility], ...]
    }
  ]

## Скоринг

Сравнение поз работает по косинусному сходству нормализованных координат 12 ключевых точек тела (плечи, локти, запястья, бёдра, колени, лодыжки). Оценка от 0 до 100, с порогами:

| Оценка | Диапазон | Описание |
|--------|----------|----------|
| S | 90–100 | Идеально |
| A | 75–89 | Отлично |
| B | 60–74 | Хорошо |
| C | 40–59 | Неплохо |
| D | 0–39 | Попробуй ещё раз |

## Технологии

- **PyQt6** — GUI
- **MediaPipe Pose** — трекинг скелета
- **OpenCV** — захват видео с камеры и воспроизведение
- **NumPy** — вычисления скоринга
