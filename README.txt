Just Dance Clone — README
==========================

Установка:
  pip install -r requirements.txt

Запуск:
  python main.py

Структура:
  main.py          — главное меню, список танцев
  dance_data.py    — модель данных, сохранение/загрузка .dance
  pose_tracker.py  — MediaPipe Pose обёртка + скоринг
  dance_editor.py  — редактор: запись поз с камеры
  dance_player.py  — игровой режим + результаты
  dances/          — папка для сохранённых танцев

Создание танца:
  1. Меню → Редактор танцев
  2. Введите название, выберите сложность и BPM
  3. (Опц.) Выберите аудио и видео-эталон
  4. Запустите камеру
  5. Нажмите «Начать запись» и танцуйте
  6. Остановите запись и сохраните

Игра:
  1. Выберите танец из списка
  2. Нажмите «Играть»
  3. Повторяйте движения перед камерой
  4. ESC — выход в меню

Требования:
  - Python 3.9–3.11
  - Веб-камера
  - Хорошее освещение
